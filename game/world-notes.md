# ANKA 地图资产模块

`createWorld(theme)` 支持 `desert`、`jungle`、`snow`、`city`。四个主题共用可预期的战斗路线，分别具备棕榈与分层砂岩峡谷、粗大雨林树与苔石遗迹、积雪针叶树与冰色要塞、夜色城市天际线与霓虹路灯。

沙漠地图为 44 × 38 米，中央 20 × 16 米保持无实体障碍；南侧出生点 `(0,0,11)`。四角兵营、北侧双哨塔与高架桥、周界低墙、两侧掩体与补给遮阳棚组成空间层级。桥底净空约 3.88 米，中央桥下通道不设碰撞。货箱、油桶、沙袋、树干、墙与建筑的平面碰撞体均与对应可见实体共同创建。

静态模型按材质合并，建筑细节、地面石屑和外缘植被不各自增加独立 draw call。只有两面旗帜保留为小型动态 Mesh。模块不添加灯、不修改渲染器，也不请求外部网络或付费服务。

返回值：

```js
{
  group, colliders, bounds, playerSpawn, enemySpawns, zones,
  lighting: { sky, fog, ground, key },
  update(deltaSeconds, elapsedSeconds),
  dispose(),
}
```

`colliders` 的字段为 `minX/maxX/minZ/maxZ/height`，附加 `label` 便于调试。场景内道路和地面约为 `y=0`；不提供二楼可通行导航。`zones` 返回有名称、中心和半径的战斗地标，方便任务与小地图标注。

## 验证结果

Node 端实际构建了四个主题，检查所有顶点值有限、全部九个出生点在 0.38 米角色半径下不与碰撞体重叠、中央 20 × 16 米区域没有实体碰撞体，并运行了旗帜更新与资源销毁。`node --check game/world.js` 通过。

| 主题 | Mesh 数（含旗帜） | 三角面 | 碰撞体 |
|---|---:|---:|---:|
| desert | 23 | 35,064 | 60 |
| jungle | 23 | 37,692 | 60 |
| snow | 22 | 36,124 | 60 |
| city | 19 | 30,268 | 60 |

浏览器中的镜头、雾和灯光最终效果由主游戏集成时检查。建议暖色主光位置 `(-12,24,8)`，场景阴影相机覆盖 50 米左右，雾从 38 米开始、100 米结束；外围山体/天际线在战斗边界之外用于远景。
