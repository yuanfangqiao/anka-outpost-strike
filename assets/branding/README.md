# ANKA 标志资源

当前采用小杰、小葵双人突击图形，保留金色圆形准星。

- `anka-logo-transparent.png`：透明底原尺寸图，用于导出、设计与后续适配。
- `anka-logo-transparent.webp`：游戏内页头、加载页和角色展示页使用的透明底图。
- `anka-app-icon-navy.png`：完整保留的蓝黑底原图，供后续 ANKA 应用图标使用。
- `anka-logo.webp`：原蓝黑底网页尺寸图，保留备用。
- `favicon.png`、`apple-touch-icon.png`：沿用蓝黑底的浏览器和主屏幕图标。
- `logo-concepts/`：历次设计方案与生成提示词。

透明版由内置 imagegen 工具去除背景，保留当前标志的角色、配色与准星设计。
