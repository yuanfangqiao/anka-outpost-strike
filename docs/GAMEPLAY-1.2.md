# 1.2：可见弹道与移动端横屏

第一人称射击增加屏幕枪口火光、向目标飞行的明亮曳光和短暂弹道余迹。
普通枪械使用暖金色弹道，能量枪保留青色，狙击弹更粗。
可见起点按武器自己的投影映射回世界相机，因此开镜、换枪后仍衔接枪口。
命中与掩体判定继续使用原来的准星射线；联机中自己的射击效果同样显示在本地枪口。

## 手机操作

- 默认横屏布局，开始任务时尝试全屏和锁定横屏，也可点击右上角全屏按钮。
- 不支持方向锁定时（例如部分 iOS 浏览器），竖屏中自动旋转整个游戏为横屏；
  摇杆与转向输入随布局换算，实际旋转手机后恢复正常横屏布局。
- 按概念图安排左下圆形移动摇杆，右侧开火、瞄准、跳跃、翻滚和蹲伏圆形按钮，
  底部中间为枪械、弹药、换弹、手雷、医疗包和护盾。
- 右侧空白处拖动转向；按住开火可以连续射击，直接拖动开火键也可同时调整瞄准。
  摇杆、开火和转向支持多指同时操作。
- 点击“换枪”打开七种武器，选中后收起；瞄准与蹲伏为点击切换，亮起表示启用。
- 松手或触控取消时释放对应操作；暂停、切后台和改变屏幕方向后清空持续输入。
- 新设备的移动端默认使用“流畅”画质，已有的画质选择优先。

## 验证

`npm run test:shots` 检查七种武器 × 两种瞄准状态 × 三种画面比例的枪口投影，
并检查弹道运动、效果池上限、命中射线起点、联机自身 / 对手效果和旋转坐标换算。

`npm run test:mobile` 需要先启动 `npm run dev`，并提供 Playwright 与 Chromium。
可用 `PLAYWRIGHT_MODULE` 和 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定本机安装位置，
用 `ANKA_QA_URL` 改预览地址。
脚本使用浏览器原生多点触摸事件，覆盖桌面 1440×900、横屏 844×390、竖屏 390×844、
小屏 568×320，检查按钮触达、移动与开火同时进行、拖动开火键转向、动作、换枪、
暂停及旋转后的输入释放。截图和结果位于 `reports/game/mobile/`。
浏览器设备模拟不等同于 iOS / Android 实体手机验收。
