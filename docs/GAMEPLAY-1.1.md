# 1.1：第一人称、地面补给与掩体复活

## 视角与操作

- 默认第一人称。点击视角按钮或按 **V** 切换第一 / 第三人称；选择保存在本机，刷新后保留。
- 桌面第一人称点击画面后锁定鼠标，移动鼠标转向，左键开火；Esc 释放鼠标。
  未锁定时可按住右键拖动转向。右键同时提供瞄准缩放。
- 手机保留移动摇杆、拖动转向、持续射击和动作按钮，视角按钮适配竖屏与横屏。
- 第一人称隐藏本地角色身体，独立渲染手臂与武器，支持换枪、开火后坐和换弹动作。
  枪械与世界分开深度渲染，避免贴墙穿模和枪械自身错误遮挡。

## 地面道具

地图上分布八个补给站。走近自动拾取，也可按 **F** 或点击“拾取附近道具”。
角色死亡、隔墙、超出距离或背包已满时不能领取；拾取后 24 秒刷新。

| 道具 | 效果 |
|---|---|
| 医疗补给 | 立即恢复 45 HP，上限 120 |
| 弹药箱 | 各武器增加两个弹匣的备用弹药，上限为基础备用量的两倍 |
| 护盾装置 | 护盾道具 +1，上限 4；按 Q 使用 |
| 手雷补给 | 手雷 +2，上限 6 |
| 医疗包 | 医疗包 +1，上限 5；按 E 使用 |

联机由房主统一判断双方是否满足拾取条件。同一个补给不会被两人重复领取，
剩余道具、库存和刷新倒计时通过房间快照同步。客人不能在本机自行增加道具。

## 对战出生与复活

四张对战地图扩展到约 59 × 51 米，加入中央高掩体、交错屏障与侧翼低掩体。
故事 / 生存模式继续使用原先的场地尺寸。

出生点分散在外围十个可通行位置。开局双方通常相隔 40 米左右，视线被实体掩体隔断。
复活时优先选择与对手相隔至少 22 米、视线被阻挡、具有撤离路线的位置，
同时降低连续使用同一位置的倾向；不可用时选择剩余候选中更安全的位置。
复活继续保留 3 秒等待与 2 秒保护。

隔墙的对手标签与对战小地图敌方位置不显示。人机的搜索与巡查范围同步适配扩大后的地图，
避免走到一半遗忘目标后停留在中央。
